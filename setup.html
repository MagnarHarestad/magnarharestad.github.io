Setting up MagMail

For MagMail 1.1 on Windows 10/11 (64-bit)

1. Run MagMail

  1. Download MagMail-win-x64.zip and unzip it, e.g. to C:\Programs\MagMail.
  2. Start MagMail.exe. If SmartScreen warns about an unknown publisher, click More info → Run anyway.

2. Connect Gmail (one time, about 10 minutes)

MagMail never asks for your Gmail password. You sign in on Google's own page, and you use your own free Google Cloud OAuth client, so no third party is involved.

  1. In Google Cloud Console, create a project and enable the Gmail API.
  2. Open Google Auth Platform and configure it: app name MagMail, user type External, your e-mail as support and developer contact.
  3. Under Audience, add your Gmail address as a Test user. To avoid having to sign in again every 7 days, click Publish app instead. For personal use no Google verification is needed; you'll just see an "unverified app" notice when signing in.
  4. Under Clients, create an OAuth client of type Desktop app and download its JSON file.
  5. In MagMail, click Import client JSON…, pick the file, then Sign in with Google. On the "Google hasn't verified this app" screen, choose Advanced → Go to MagMail and allow access.

3. AI assistant (optional)

Local and free (default). Install Ollama and the Qwen3 14B model in PowerShell. Reopen PowerShell after the first command:

winget install --id Ollama.Ollama -e
ollama pull qwen3:14b

The model is about 9 GB and works best with an NVIDIA GPU with 12 GB of memory. In MagMail, open Settings → AI assistant → Test connection. With the local model, no mail ever leaves your PC.

Claude. Choose Claude via the Anthropic API in Settings and paste an API key from console.anthropic.com (pay per use; a Claude Pro subscription doesn't include API access).

Where MagMail keeps things

  • Settings: %APPDATA%\MagMail. Login, OAuth client and API key are encrypted (Windows DPAPI) in its secure folder.
  • Encrypted mail cache: %LOCALAPPDATA%\MagMail.
  • To remove everything: Settings → Sign out & revoke access, then delete the MagMail folder and those two folders.
